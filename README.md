# KFC Tajikistan Demo Landing

Это demo-лендинг для портфолио. Это не официальный сайт KFC.

## Что внутри

- выбор языка перед открытием сайта
- кнопка смены языка в правом верхнем углу
- русский и английский язык
- красно-чёрный дизайн под KFC
- адаптация под телефон
- анимации при скролле
- динамичная hero-секция
- карточки меню
- блок комбо
- блок доставки
- реальные публичные ссылки KFC Tajikistan

## Реальные ссылки, которые уже стоят в проекте

- Instagram: https://www.instagram.com/kfcintajikistan/
- Facebook: https://www.facebook.com/kfcintajikistan/
- Menu: https://www.kfc.tj/menu

## Как запустить

Просто открой `index.html` в браузере.

## Как загрузить на Railway

1. Создай GitHub репозиторий.
2. Загрузи туда эти файлы.
3. В Railway нажми New Project.
4. Выбери Deploy from GitHub repo.
5. Выбери репозиторий.
6. Получишь ссылку на сайт.
