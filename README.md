# Aurum Coffee Landing Page

Готовый demo-лендинг для портфолио.

## Файлы

- `index.html`
- `style.css`
- `script.js`

## Что есть внутри

- первая страница выбора языка
- русский и английский язык
- тёплый дизайн под кофейню
- адаптация под телефон
- анимации при прокрутке
- меню
- галерея
- блок бронирования
- кнопки Instagram / Telegram / WhatsApp
- отправка брони в WhatsApp

## Как изменить ссылки

В `index.html` замени:

- `https://instagram.com/aurumcoffee`
- `https://t.me/aurumcoffee`
- `https://wa.me/992000000000`

В `script.js` замени:

```js
const whatsappNumber = "992000000000"
```

на настоящий номер кофейни.
